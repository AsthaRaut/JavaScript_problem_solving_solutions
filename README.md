# JavaScript Problem Solving

A collection of **JavaScript problem-solving exercises** focused on building strong programming fundamentals, logical thinking and writing efficient solutions.

## Overview

This repository covers problems progressing from **basic logic to loops and nested loops, followed by Arrays and Objects**.

The solutions are primarily implemented using **core JavaScript logic**, with minimal reliance on built-in methods. The focus is on understanding the logic behind each problem and improving solution efficiency.

## Topics Covered

- JavaScript Fundamentals
- Conditional Statements
- Loops
- Nested Loops
- Arrays
- Objects
- Logical & Pattern-Based Problems
- Code Optimization
- Time & Space Complexity

## Problem-Solving Approach

- Understand the problem and define the logic before coding
- Implement solutions using fundamental JavaScript concepts
- Avoid unnecessary built-in methods to strengthen core logic
- Reduce unnecessary iterations and operations
- Keep solutions clean, readable and efficient
- Consider **Time Complexity** and **Space Complexity**

## Tech Stack

- **JavaScript (ES6+)**
- **Node.js**
- **HTML** — for selected practice files

## Goal

To strengthen **problem-solving skills, logical thinking, and JavaScript fundamentals** while building a strong foundation for **Data Structures and Algorithms (DSA)**.
